2026 Person re-identification in videoRecognizes the same person across video frames, with 92.4% identification accuracy. Built withYOLOv8, DeepSORT, CNN, HOG and LBP features

Can a model recognize the same person across video frames and keep their identity consistent?

How it works

  1. DetectYOLOv8 finds each person in every frame.
  2. TrackDeepSORT follows each detection across frames and keeps its ID consistent.
  3. DescribeA CNN re-identification model, combined with HOG and LBP features, captures how each person looks.
  4. Re-identifyThose appearance features match people to the same identity when they reappear.
  5. OrganizeEach identity's detections are saved to its own folder for review.

2024 Deepfake detectionClassifies videos as real or manipulated using spatial and temporal features from their frames. Built withResNeXt, LSTM, video preprocessing

Can a model tell real videos from manipulated ones?

How it works

  1. PrepareVideos are split into frames and preprocessed.
  2. Look within framesA ResNeXt CNN extracts spatial features that expose facial inconsistencies.
  3. Look across framesAn LSTM reads the frame sequence to catch temporal artifacts.
  4. DecideThe model flags each video as real or manipulated.
